Release notes, kernel-style

New in this build

  • Agent mode — the phone can carry out a task you type, on its own: it reads the screen, decides the next step and does it until the task is done or you stop it. Off by default. You supply your own model endpoint and key, so BestROM runs no endpoint and receives nothing, and what a task sees on the screen goes to the endpoint you named while the task runs. It asks before anything that changes something, refuses lock screen, bootloader, developer, accessibility and payment actions whatever you allow, and turns itself off when the phone restarts.
  • Cromite WebView — the engine every app uses to show a web page is Cromite's build instead of the AOSP Chromium prebuilt, built from BestROM's own fork of Cromite so that a page can no longer crash the app showing it. No variations, metrics or component-update endpoints; the costs are no certificate-revocation updates between releases and a build four Chrome majors behind the one it replaces.
  • LeanType keyboard — replaces the AOSP keyboard, opens at full size and brings its own spell checker. It is signed with the ROM key, so it updates by OTA only.
  • Monochrome Settings — a true-black system theme with dot-matrix type on the lock screen, every Settings row its own card with an outlined letter glyph, and no window blur anywhere. Pure black dark theme is on out of the box.
  • Edge gestures — swipe gestures along the screen edges, hardware key remapping, a pie menu, side panels and clipboard history, preloaded as its own app. Nothing happens until you assign a gesture.
  • Ad and tracker blocking — a DNS-level blocker for ads, trackers and malware is part of the ROM and on out of the box. It works inside the system resolver, so it needs no root and does not take the VPN slot. An optional deep mode, off by default, covers apps that go around the resolver.
  • Camera — MiuiCamera is the camera again, and photos taken with it now appear in the gallery.
  • Files — MiXplorer is preloaded alongside Via as a normal, removable app.

Built on other people's work

VoltageOS 6.1, LineageOS and AOSP underneath. Cromite for the WebView, LeanType for the keyboard, a native port of EdgeX for the edge gestures, MiXplorer and Via preloaded unmodified, Doto and Space Grotesk under the Open Font License. Full list, with licences and links: Credits.
