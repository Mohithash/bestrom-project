BestROM

Android 17 for the POCO F6 / Redmi Turbo 3 (peridot)

BestROM is a product layer on top of VoltageOS 6.1, which is itself built on LineageOS and AOSP. The priority is battery life and a plain dark interface, not skins or feature count. Every fork under this account keeps its upstream history, authors and notices.

Root

Not included in the ROM zip. If you want root, the recommended kernel is Theettam 2.8, GKI 6.1.176, built for peridot. Flash one flavor in recovery after the ROM. Back up boot and vendor_boot first, and do not flash a boot image by itself.

Changelog

  • Keyboard — LeanType no longer crashes when the suggestion strip is not created yet.
  • DNS blocking — the boot seeder now decodes the baked baseline, so the filter actually arms.
  • Games — Edge enters Game Mode on its own while a game is in front, and disarms the global input filter until you leave it.
  • Theme — one chrome across Settings, Quick Settings and the launcher: 22dp cards, Space Grotesk, Doto on the clock, pill tiles.
  • Agent mode menu entry — fixed the Agent mode rows being added to a Custom Tweaks screen that nothing displays, so there was no way into the feature from Settings. They are now on the Advanced tab.
  • Agent mode — the device can carry out a typed task on its own. Off by default, disabled again on reboot. You supply the model endpoint and key; no endpoint is run by this project. It prompts before any action that changes state, and refuses lock screen, bootloader, developer, accessibility and payment actions.
  • WebView — replaced the AOSP Chromium prebuilt with Cromite 148.0.7778.168, built from a fork that disables the self-check that crashed host apps. No variations, metrics or component-updater endpoints. It receives no certificate-revocation updates between releases and trails the prebuilt by four Chrome majors.
  • Keyboard — replaced the AOSP keyboard with LeanType 4.2.0, defaulting to full height and width, with its own spell checker. Signed with the ROM key, so it updates by OTA only.
  • DNS blocking — ad, tracker and malware blocking in the system resolver, enabled by default. No root, no VPN slot. An optional deep mode covers apps that bypass the resolver.
  • Edge gestures — edge swipes, key remapping, pie menu, side panels and clipboard history, as a separate app. Inactive until a gesture is assigned.
  • Theme — monochrome, true black by default, with dot-matrix type on the lock screen and no window blur. Settings redrawn as individual rows.
  • Camera — switched back to MiuiCamera. Fixed captures not appearing in the gallery.
  • Files — preloaded MiXplorer as a removable user app.
  • Branding — removed the remaining VoltageOS marks from the Updater, status bar and About phone.

Installation

Dirty flashing over an earlier BestROM build is supported. Coming from another ROM, wipe data first.

adb reboot recovery
# Recovery -> Apply update -> Apply from ADB
adb sideload BestROM-3.0-peridot-20260912-0407-OFFICIAL.zip

The zip installs to the inactive slot and activates it. The first boot takes several minutes while apps are compiled.

Customize

Use ServerHive for this. A BestROM tree is not a laptop build. Open an environment there, sync the manifest, and point Cursor, Claude Code or Codex at that checkout. The MCP server then syncs, builds a module, verifies the image and reads device logs. The build gates stay on. It needs Python 3.11 or newer and uv. Approve .mcp.json once; the first connection creates the environment.

curl -LsSf https://astral.sh/uv/install.sh | sh

ServerHive ServerHive guide MCP guide AGENTS.md Client config

Path

  1. 1 · ServerHiveOpen an environment at serverhive.in. Do the rest there, not on a laptop.
  2. 2 · Syncrepo init the BestROM manifest, branch 17, then repo sync.
  3. 3 · ConnectOpen that checkout in Cursor, Claude Code or Codex and approve .mcp.json.
  4. 4 · ChangeAsk the agent. It edits through the MCP tools, builds the module, and runs the image gate.
  5. 5 · FlashSideload the zip from recovery. Do not flash a boot image by itself.
